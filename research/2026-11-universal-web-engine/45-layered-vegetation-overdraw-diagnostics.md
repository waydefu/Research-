# 密集植被渲染：逐層消融、透明過繪與畫質驗收

查核日期：2026-11-24。來源為公開圖形工程 PR 描述與可見差異，真機數據為來源作者記錄，未獨立重跑。

## 從畫面規格到瓶頸

高密度植被可用固定世界根位、完整葉網格、簡化葉網格、交叉草片、遠景地表覆蓋等表示。各 LOD 應維持輪廓、根部接地、風場、遮蔽與地形法線連續；基準高模及可任選區域的對照比只看一張精選近照更有效。

透明草片即使三角形少，也可能由像素過繪、混合與無效透明區域主導 GPU 成本。不可從三角形數推論瓶頸。逐層停繪但保留其他選取、光照、位置與品質權重，分開測量葉網格、草片和草冠取樣。記錄實際後端、解析度、視野、裝置、GPU feature、p50/p95/p99 frame time、CPU/GPU 時間及熱狀態。

## 候選方法

- 用母版 alpha 覆蓋裁掉空透明頂部，保留過濾邊，避免斜坡、mip 及邊緣取樣出現破洞。
- 在支援的 MSAA 路徑比較 alpha-to-coverage 與深度寫入，降低重疊混合成本；與一般半透明、alpha test 分開測。可能改變細葉輪廓、遮擋及閃爍，無支援須明確回退。
- 近中景的底色融合與立體光影退場使用分離的過渡；地形高度取樣可推導斜坡法線，避免平面法線造成色差圈。不得宣稱所有引擎都零額外取樣。
- 在距離與 LOD 選擇後獨立測視錐剔除及區塊層級；檢查剔除邊界、移動中重建峰值與可見物消失。固定曝光做全域天光對照，避免自動曝光掩蓋差異。

## 有限數據與結論

公開案例記錄固定手機站姿、WebGPU Medium、100% 直向渲染比例：全開 9.1 FPS，停繪草片 20.1 FPS；同一時間窗平均幀間隔約 109.1 與 48.6 ms。該差異是兩種完整配置的觀察，不是獨立 GPU timestamp，不能認定 60.5 ms 都是草片 GPU 成本，亦不能外推其他裝置。停繪本身不滿足畫質；裁邊與深度方案的真機成效仍待驗證。60 FPS 約需 16.67 ms 每幀，仍須查其他層。

## 可重現驗收

固定母版、根位、鏡頭、渲染尺寸、光照與場景；先站姿短測，再斜坡、低地、高地、接縫與移動路線；冷機與至少十分鐘熱機分開，重複順序並報告完整分布。收集截圖／影片及實際後端；先驗視覺同等，再比較速度。變體以可關閉參數隔離，失敗回到基準。沒有 GPU timing 時標未知，不能以單一 FPS 認定最佳化完成。
