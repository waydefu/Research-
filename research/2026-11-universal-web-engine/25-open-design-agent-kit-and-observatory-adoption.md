# Open Design Agent Kit｜工具研究

查證日期：2026-11-03。

官方原始碼：https://github.com/feimacode/open-design-agent-kit

這是一套協助 Codex、Claude Code 等程式代理進行 UI 設計的開發工具，而不是網頁訪客端套件。它提供設計工作方法、設計系統、可改寫的範例與瀏覽器畫面檢查。

Research- 的導入方向：依照使用者提供的暗金天文神殿參考圖，優先改善首頁搜尋、繁體中文導覽、不同研究主題的具體配圖，以及讓非專業讀者看得懂的父子分類說明。研究原文與原作者連結必須保留。

安裝與實際工具調用需在已連接的開發環境中完成。現階段未驗證該工具在本專案內執行，不能宣稱已安裝或已產生頁面。
