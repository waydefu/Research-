## 要解決什麼問題

Grassworks 是 Tech Redux 販售的商用草地系統，專為 Three.js 的 WebGPU 渲染器與 TSL（Three.js Shading Language）設計。使用者提供的展示頁是它的官方 demo：在森林裡的廢棄屋中第一人稱行走，草地隨風擺動。

本篇回答：它**實際宣稱與證實了什麼**、**和以 WebGL2 為基線、不採 WebGPU-first 的網站專案有什麼關係**、**現在能借鏡什麼、不能做什麼**。

## 主要結論

- **已證實（頁面可重現，2026-11-06）：**
  - 展示頁文字說明：第一人稱走過森林裡的廢棄屋，有擺動的草、松樹與梣樹、落葉與漂浮孢子，即時渲染。操作為「點擊進入、WASD 行走、滑鼠環顧、Shift 衝刺」。頁面要求 JavaScript，並明示需使用桌機版新版 Chrome 或 Edge；偵測不到 WebGPU 時顯示「WebGPU not available」的說明。
  - 展示頁載入的 JS 約 2.4 MB（2,410,331 bytes），其中的 Three.js `REVISION` 為 `"187"`，與本庫研究的 Three.js r187（見 [27](27-threejs-r187-ultra-rendering-ceiling.md)）是同一版本。這是對公開 bundle 的字串比對，**不代表已審查它如何使用 Three.js**。
  - 產品頁宣稱：一次買斷 **US$100**；v1.2.0 的 ZIP 為 1.7 MB，內含 `grassworks.min.js`、`src/` 原始碼、基本範例與範例素材、一份給 LLM 的 Skill（`THREEJS_GRASSWORKS_SKILL_v1.2.0.md`）與 `LICENSE.pdf`。
  - FAQ 自述：為 WebGPU 而建、**沒有獨立的 WebGL 實作**（可使用 Three.js 內建的 WebGL 後備，但設計與優化針對 WebGPU）；完整以 TSL 建構。
  - 功能列表（產品自述）：以相機為中心的無限分塊草地、距離與視錐剔除、四級 LOD、12 種預設草種、葉片與 billboard 兩種草、地形感知、程序風場、互動變形、Grass Map／Color Map 與場景內的 Terrain Painter。
- **有條件成立：** 「即時渲染大量草地」「可擴展的效能」是產品自述，**沒有公開的可重現 benchmark**（裝置、場景、FPS、GPU 時間均未標示）。
- **尚待驗證：** 實機 FPS、記憶體與發熱；手機瀏覽器能否執行；TSL 草地在非 WebGPU 後備下的畫質與效能；原始碼品質。本研究環境的瀏覽器 `navigator.gpu` 不存在，**展示頁無法在此執行，標為 NOT RUN**。
- **需特別注意（授權，詳見下節）：** 條款明文限制把產品原始碼用於 AI 訓練、檢索與重製。**公開研究庫若有全文索引與 Agent 檢索工具，就不得把購得的原始碼放進來。**

## 沉浸網站可以借鏡什麼（設計建議）

若網站專案以 WebGL2 為基線、不採 WebGPU-first，Grassworks **不是可導入的零件**。但這個展示在體驗設計上有可對照的地方：

1. **進入流程。** 「載入素材 → Start → 點擊進入＋操作提示」把沉浸體驗與頁面載入分開，使用者不會被突然搶走游標或捲動。這與「3D 只在捲到場景時載入、不接管捲動」的漸進增強原則方向一致。
2. **不支援時的說法。** 展示頁在沒有 WebGPU 時只顯示說明，**沒有可閱讀的替代內容**；較好的做法是提供海報與可閱讀內容的後備，讓內容不依賴 WebGPU。
3. **「世界連續」的樣本。** 單一場景內的天氣粒子（落葉、孢子）與風場讓畫面持續有生命感，可作為沉浸場景氛圍層（微粒、呼吸感光暈）的參考。**輕量的微粒與光暈可在 WebGL2 內完成，不需要 WebGPU。**
4. **Agent 友善的散布方式。** 商品把一份 LLM Skill 與程式碼一起出貨，和本庫 [34](34-forever-components-agent-retrieval-and-web-effects.md)（Agent 元件檢索）的方向相同；但本例的條款對 AI 使用有明確界線，與開源元件的情形不同。
5. **TSL／WebGPU 路線的旁證。** 它顯示在 r187 上以 TSL 建構大型即時場景是有商用產品在做的；這可作為 [27](27-threejs-r187-ultra-rendering-ceiling.md)、[29](29-rendering-ceiling-benchmark-and-adoption-gates.md) 中「受測的 WebGPU/TSL 路線」的外部參考。**它不是效能證據。**
