## 研究結論

資訊系統不等於程式碼；人員、資料、流程與軟硬體必須共同設計。系統開發從需求和問題開始，立案前要衡量可行性與投資價值，執行期間則需持續控制任務依賴、資源、範圍與風險。敏捷開發允許反覆修訂，不等於所有專案都應採用固定線性流程。
