# Research-｜原始神殿參考圖與設計代理工作規範

**日期**：2026-11-03。**原始參考**：Owner 於對話提供的 1087 × 1536 天文觀測神殿畫面。此圖作為設計驗收依據，不等於已取得可重複使用的網站背景資產。

## 需還原的重點

深藍拱頂、暗金天文儀、具體可辨識的建築與器械、少量冰藍反射。**保持整體場景連續，不是每個分類都再貼一次神殿圖。** 首屏就有清楚的搜尋研究入口及熱門主題，右側快速導覽可直接開啟資料。下方依序展示精選研究、最近更新、圖文分類與真實統計。

## 閱讀與分類規範

每一個父分類都要有獨立的主題圖片及白話解釋，包括「這是什麼／實際用途／適合誰」。子分類不能只有名詞，必須說明會學到什麼，附可閱讀的文章入口。文章先用零基礎生活例子，再講技術原理、限制、作者作品及相關示範。**所有一般介面內容使用繁體中文**；Three.js、Astro、WebGL 等專有名詞可以保留原文，但首次出現要解釋。

具體圖像方向：網站設計→編輯器、實際網頁或互動場景；AI 代理→可辨識的工作流程及機器裝置；資料庫→伺服器、查詢界面；安全治理→驗證器、權限或稽核畫面；工程測試→程式與測試結果；研究方法→書籍、文獻及檢驗工具。**禁止所有研究共用同一張圖，或拿抽象光圈代替具體內容。**

## Open Design Agent Kit 使用要求

官方工具：https://github.com/feimacode/open-design-agent-kit。可將這份規範作為設計 Brief，透過已連線的 Codex／Claude Code 工具選擇設計方法、建立可操作的桌面／手機草稿、比較不同構圖，再轉成現有 Astro 頁面。**工具未連線時不可聲稱已使用其 MCP；設計稿未經瀏覽器截圖與 Owner 簽核前不可直接部署。**

驗收：320／393／768／1440px、鍵盤及無 JS 退化可用；文章計數來自真實資料，不可複製示意圖中的 128、7,430 等數字；原作者及 demo 保留可追溯連結且不強制載入第三方 iframe。首頁可在第一視窗找到搜尋，從父分類到文章每層都能理解與回退。
