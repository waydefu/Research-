# ADR-0001｜保留研究來源，分離編輯正文與視覺層

- **狀態**：Accepted — 僅描述現行 Astro 內容網站的維護邊界
- **日期**：2026-11-04（Asia/Taipei）
- **授權界線**：不授權新 3D runtime、合併、部署、原始研究改寫或新的全站重構

## Context

公開讀者需要的是可理解、可搜尋、可追溯的技術文章，不能被特定 Repo 的歷史交接取代。當前已有 Astro 靜態閱讀、Pagefind、逐篇人工導讀、來源 SHA、通用技術正文編輯層及程序化圖像。

## Decision

保留 Markdown 為原始證據；獨立的 metadata／編輯正文／圖片層只加工**展示**；Astro 頁面負責可存取 HTML。顯示共用 Token 與行動版交互遵守少動效、DOM 優先，讓 GPU、JavaScript 或外站 iframe 不可用時仍能閱讀。Repo library 不得反向依賴 page/layout/style，避免介紹頁反過來支配研究來源。

## Alternatives

- 原始 Markdown 直接批量取代為通用文章：拒絕，會抹除歷史證據與 SHA。
- 把所有畫面壓進單一 Canvas 或 3D 引擎：拒絕，破壞無 JS 與輔助技術的閱讀路徑。
- 立即搬遷全部 CSS、加入框架或新依賴：本包暫不採用，需先有設計 Token、模組邊界及回歸證據。

## Consequences

低成本優點是來源與公開介紹可分別修訂，新研究可循一致的資料流加入。代價是須追蹤原文與公開編輯版本是否一致；截至 #53 正式合併的 2026-11-04 基線，尚有 **47 篇**未完成通用技術正文（已完成 40/87 篇；另外 47 篇仍保留原文、待人工逐項審核），大型 CSS 拆分、像素級視覺回歸及真實裝置效能仍未完成。不得把本 ADR 當成上述工作已驗收。
