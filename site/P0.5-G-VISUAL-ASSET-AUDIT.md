基線：2026-11-03 main `40cf4e861bef2f686dfdacac2e6b1e0afe4b4d9d`。本 PR 只新增 **site/ 原創 SVG 技術示意圖**，不是原作者作品截圖。

## 製作方式與法律／證據邊界

- `site/src/lib/research-visuals.mjs` 依 87 份來源的文件類型、精確標題、標籤與主題製作不同的示意結構。**審查修正：** 原本有 26 篇共用通用「證據文件」母題；現在分出來源清單、研究目錄、模板、規則、路線圖、評測等 25 種主題母題，並以 6 種畫面構圖和文章標籤製作可見的示意差異，不再只憑每張獨立檔名宣稱不同圖片。
- `site/scripts/generate-research-art.mjs` 在現有 `preflight` 階段產生 `site/public/research-figures/research-<hash>.svg`，並附 `manifest.json`（文章來源、SVG、alt、素材型態、作者示意標記、腳本來源、授權資訊）。
- 所有示意圖由本 Repo 內的 SVG 程式碼繪製；**不抓取、複製、反向工程原作者截圖、照片或商標**。不嵌入字體檔，顯示依瀏覽器系統字型。
- 全部圖片的性質為「本站原創研究示意圖」，`originalWork: false` 表示它**不是研究對象本身的原始作品**，不是原始 benchmark 或真正的遊戲畫面。主題意象和事實來源仍以原文為準。
- 已有的領域／細分類導覽圖片仍屬分類層級，沒有冒稱那是每篇文章的圖片；典藏清單和文章內頁改用逐篇獨立 SVG。
- `site/public/research-figures` 為 build-time 產出；不在 Git 提交 87 個易過期的複本，需隨完整 Repo build 重建。
- 若未來採用原作者圖片，須另有來源／授權證據；目前 **不自動顯示任何未經授權的第三方素材**。

## 測試與限制

- `site/tests/research-visuals.test.mjs`：87 篇覆蓋率、獨立路徑、SVG 禁止 scripts／外部圖片／事件處理器、至少 25 種母題、每種最多 9 篇、6 種布局、至少 65 組母題／布局組合、未審核文件回退。**仍不能靠自動化證明 87 張的美術水準與畫面涵義全部無誤**。
- `site/tests/pages/research-visuals.spec.mjs`：87 個不同 src、圖片可載入、手機無橫向溢出、原始 SHA 資料仍顯示。
- 依 PR HEAD 重跑三組 GitHub Actions：Research integrity、V3 P0 build + e2e、Publish Showcase **驗證**，不得將 PR 的 publish job 當成正式上線。
- 原創程式化圖形是可用的內容相關示意圖，**不是每篇經人工美術總監評估的正式攝影或 3D 素材**；視覺質感與真機色彩、效能仍屬 G0 / 後續手工審查。
- 本 PR 不更動 `research/`、`docs/`、`showcase/`、Ruleset、workflow、真正的部署或 P2。
